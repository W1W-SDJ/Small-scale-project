Blob Pet 资讯桌宠 —— 免安装版
================================

怎么启动
--------
1. 把整个文件夹解压到一个你愿意长期放着的位置
   （不要直接在压缩包里双击运行）。
2. 双击 start-pet.cmd（或者直接双击 electron.exe）。
   第一次启动会在右下角出现桌宠，约 5 秒后开始抓取，抓到内容会冒气泡。
3. 退出：右键桌宠 → 退出桌宠。

想让它像普通软件那样从桌面点开？
--------------------------------
双击一次本文件夹里的「创建桌面快捷方式.cmd」，它就只在桌面放一个快捷方式
（不安装任何东西、不写注册表、不开机自启）。
以后从桌面图标点开即可；就算把整个文件夹搬到别处，重跑一次这个脚本就行。

为什么不是安装程序？
--------------------
本程序没有数字签名，而 Windows 11 的 Smart App Control 在强制模式下会
直接拦截未签名的安装包（双击无反应）。文件夹形态里的 electron.exe 是
**Electron 官方未经修改的原始二进制**——它本身也没有数字签名，但被大量
用户使用过、享有信誉，所以能通过；所以用"解压 + 一个 .cmd"代替安装程序，
兼容性最好。

Windows 提示"已保护你的电脑"？
------------------------------
本程序没有数字签名，可能出现两类拦截：

* SmartScreen（蓝色窗口，"Windows 已保护你的电脑"）
  → 点「更多信息」→「仍要运行」。

* Smart App Control（强制模式下**没有任何提示**，双击就是没反应）
  这是 Windows 11 的安全策略在拦截未签名程序。
  本文件夹里的 electron.exe 是 Electron 官方原始文件（未做任何改写，哈希与
  官方发布一致），通常不会被拦；如果仍然没反应，可以去
  设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制 → 智能应用控制
  查看它是否处于"开启"状态（关闭它是系统级选择，请自行权衡）。

怎么用
------
* 左键拖动桌宠；点它一下打开摘要面板；右键有「查看摘要 / 换皮肤 / 立即刷新 / 退出」。
* 面板里每张卡片点一下就在浏览器打开原文；「⤢ 添加」可以把任意网址立刻抓成摘要。
* 面板 ⚙ → 抓取站点：默认盯的是中国农业大学校内四站，可以换成你自己的站，
  填名称 + 列表页地址即可（不要求 RSS）。
* 面板 ⚙ → 关注主题：只保留你勾选的主题（竞赛 / 实习招聘 / AI / 保研 / 校内通知），
  主题词也可以自己加。
* 面板 ⚙ → 桌宠皮肤：内置两款，也可以把自己喜欢的图片拖进面板，
  会自动去背景、裁到主体。

数据在哪
--------
%APPDATA%\Blob Pet\
  config.json     站点 / 主题 / 刷新间隔等设置
  digest.json     已抓到的摘要
  pet-state.json  桌宠位置
  pet-diag.log    运行日志（出问题时看这个）
  skins\          你导入的皮肤

删掉 config.json 会恢复默认设置；删掉 digest.json 会清空摘要。

它不联网做什么
--------------
只请求你配置的那几个网页（以及你粘贴链接时的那一页）。
没有任何遥测、不需要登录、不需要 API key；
如果以后想用大模型改写摘要，在 ⚙ → 摘要引擎里填接口和 key 即可，不填就走本地规则。
